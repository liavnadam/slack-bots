### שלב 2: מצאו קבוצות פייסבוק בפתח תקווה

1. **חפשו בפייסבוק:**
   - "דרושים פתח תקווה"
   - "משרות פתח תקווה"
   - "חיפוש עבודה פתח תקווה"
   - "דרושים מרכז"
   - "Job search Petah Tikva"

2. **הצטרפו לקבוצות** (לפחות 3-5 קבוצות פעילות)

3. **העתיקו את מספרי הקבוצות:**
   - היכנסו לקבוצה
   - הסתכלו ב-URL: `facebook.com/groups/123456789/`
   - המספר `123456789` זה מה שאתם צריכים

4. **ערכו את `groups.json`:**

```json
[
  {
    "group_id": "123456789",
    "name": "דרושים פתח תקווה",
    "city": "Petah Tikva",
    "description": "Job opportunities in Petah Tikva"
  },
  {
    "group_id": "987654321",
    "name": "משרות מרכז",
    "city": "Petah Tikva",
    "description": "Jobs in center area"
  }
]
```

או השתמשו בקובץ המוכן:
```bash
cp groups_petah_tikva.json groups.json
# ואז ערכו את groups.json והחליפו את REPLACE_WITH_REAL_GROUP_ID
```

### שלב 3: השיגו מפתחות API

#### מפתח פייסבוק

1. לכו ל-https://developers.facebook.com/
2. צרו אפליקציה (או השתמשו בקיימת)
3. **Tools** → **Graph API Explorer**
4. לחצו "Generate Access Token"
5. תנו הרשאות:
   - `user_posts`
   - `groups_access_member_info`
   - `publish_actions`
6. העתיקו את הטוקן

**להפוך לטוקן ארוך טווח (60 יום):**
- https://developers.facebook.com/tools/debug/accesstoken/
- הדביקו את הטוקן
- "Extend Access Token"
- העתיקו את הטוקן החדש

#### מפתח OpenAI

1. https://platform.openai.com/
2. התחברו
3. API Keys
4. צרו מפתח חדש
5. העתיקו אותו

#### שמרו במקום הנכון:

```bash
cp .env.example .env
```

ערכו את `.env`:
```
FACEBOOK_ACCESS_TOKEN=הטוקן_שלכם_מפייסבוק
OPENAI_API_KEY=המפתח_שלכם_מאופן_AI
```
