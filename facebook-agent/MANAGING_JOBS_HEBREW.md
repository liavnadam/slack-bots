# ניהול משרות - איך להוסיף, לערוך ולמחוק משרות בקלות

## 🎯 מה השתנה?

**התגובות עכשיו מבקשות מאנשים לשלוח לך הודעה פרטית!**

במקום לכלול קישור להגשת מועמדות, הבוט עכשיו מבקש מאנשים:
> "שלחו לי הודעה פרטית לפרטים נוספים והגשת מועמדות"

זה נותן לך:
✅ שליטה מלאה על התהליך
✅ אפשרות לסנן מועמדים
✅ קשר אישי יותר
✅ גמישות בהגשת המועמדויות

---

## 📋 איך להוסיף את 9 המשרות הנוספות שלך?

יש לך **3 אפשרויות קלות**:

### אפשרות 1: ממשק ניהול המשרות (הכי קל!) ⭐

הרץ את הפקודה:
```bash
python manage_jobs.py
```

תקבל תפריט פשוט:
```
1. 📋 הצג משרות - List all jobs
2. ➕ הוסף משרה - Add new job
3. 🚀 הוספה מהירה (העתק והדבק)
4. ✏️  ערוך משרה - Edit job
5. 🗑️  מחק משרה - Remove job
6. 💾 שמור - Save
7. 🚪 יציאה - Exit
```

**להוספת משרה:**
- בחר 2
- ענה על השאלות (העתק והדבק מ-Correct Tech שלך!)
- זהו! המשרה נוספה

**הוספה מהירה (copy & paste):**
- בחר 3
- הדבק את כל הטקסט של המשרה מ-Correct Tech
- הכלי יצור משרה אוטומטית
- תוכל לערוך אחר כך אם צריך

### אפשרות 2: הכלי האינטראקטיבי

```bash
python setup_petah_tikva_jobs.py interactive
```

זה ידריך אותך להוסיף את כל 10 המשרות אחת אחרי השניה.

### אפשרות 3: הכלי הכללי

```bash
python job_entry_helper.py
```

- בחר 1 - "Add new job (interactive)"
- ענה על השאלות
- חזור על זה 9 פעמים (למשרות הנוספות)
- בחר 5 - "Save to jobs.json"

3. אישור - המשרה נמחקה!

## 📊 מבנה קובץ המשרות

קובץ ה-`jobs.json` נראה כך:
```json
[
  {
    "title": "שם המשרה",
    "location": "פתח תקווה, ישראל",
    "city": "Petah Tikva",
    "requirements": [
      "דרישה 1",
      "דרישה 2"
    ],
    "description": "תיאור מלא...",
    "url": "private_message",
    "salary": "₪10,000 - ₪15,000",
    "job_type": "Full-time",
    "experience_level": "Mid"
  }
]
```

**הערות חשובות:**
- `url` תמיד `"private_message"` - הבוט יבקש הודעה פרטית
- `city` תמיד `"Petah Tikva"` - זה לזיהוי קבוצות
- `requirements` - רשימה של דרישות (כל דרישה בנפרד)

## ❓ שאלות נפוצות

### ש: כמה משרות אני יכול להוסיף?
**ת:** ללא הגבלה! הוסף כמה שאתה רוצה.

### ש: מה אם אני רוצה למחוק את כל המשרות ולהתחיל מחדש?
**ת:**
```bash
# גבה את הקובץ הנוכחי
cp jobs.json jobs.json.old

# צור קובץ ריק
echo "[]" > jobs.json

# התחל להוסיף משרות חדשות
python manage_jobs.py
```

### ש: האם אני יכול לערוך את jobs.json ידנית?
**ת:** כן! אבל שמור גיבוי קודם. השתמש ב-`manage_jobs.py` כדי להיות בטוח.

### ש: מה קורה אם טעיתי ומחקתי משרה?
**ת:**
```bash
# מצא את הגיבוי האחרון
ls -lt jobs.json.backup-*

# שחזר ממנו
cp jobs.json.backup-20251102-123456 jobs.json
```

### ש: איך אני משנה את התגובה שהבוט שולח?
**ת:** ערוך את `facebook_job_agent_v2.py` - חפש `comment_prompt_with_job`
